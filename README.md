NEON VOID is a neon wave space shooter: pilot the last starfighter through 10 waves of void spawn, defeat the VOID HEART boss, and bring the light back. Four enemy kinds, two bosses, spread-shot / shield / repair / star pickups, bombs, a kill-streak multiplier, particles, screen shake and synthesised WebAudio sound — all in plain static files, no build step, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Move with arrows / WASD or the mouse — the gun fires on its own. Shift or B: bomb. P: pause. M: mute.
